# Viby

Viby 是本地优先的 AI 代理远程控制桌面应用。

你的 AI 继续跑在自己的电脑上；打开 Viby Desktop，就能从桌面、浏览器或手机查看进度、发消息、审批、看文件和打开终端。

## 你能得到什么

- 在手机 / 浏览器 / 桌面随时查看并继续电脑上的 AI 会话
- 实时看 AI 输出，发送消息、附件、重试与审批
- 浏览文件、Diff 与终端
- 数据留在你自己的电脑，扫码即连

## 支持的代理

- 核心：Claude Code、Codex、Pi
- 实验：Gemini、Cursor Agent、OpenCode、GitHub Copilot

## 快速开始

1. 安装并打开 Viby Desktop。
2. 让它保持后台运行。
3. 用手机扫码连接，即可远程查看和操作。
